### 11.3  מטריצת ז'ורדן המתאימה לערך עצמי

- הגדרה 11.3.1 - מטריצת ז'ורדן יסודית המתאימה לערך עצמי $`J_{n}\left(\lambda\right)=\lambda I+J_{n}\left(0\right)`$
- טענה 11.3.2 -
  - $`M_{J_{n}\left(\lambda\right)}=P_{J_{n}\left(\lambda\right)}=\left(x-\lambda\right)^{n}`$
  - ‏$`J_{n}\left(\lambda\right)`$ הפיכה אם ורק אם $`\lambda\neq 0`$.
  - אם $`n>1`$ אז $`J_{n}\left(\lambda\right)`$ לא לכסינה מעל שום שדה הרחבה.
- הגדרה 11.3.3 - מטריצת ז'ורדן המתאימה לערך העצמי $`\lambda`$.
- הערה 11.3.4 - כדי לעבור בין מטריצת ז'ורדן של 0 ל-$`\lambda`$ אפשר להוסיף $`\lambda I`$, $`\tau_{m}\left(J,\lambda\right)=\tau_{m}\left(J-I\lambda,0\right)`$.

- טענה 11.3.6 - $`J_{n}^{m}\left(\lambda\right)=\sum_{i=0}^{min\left(m,n-1\right)}{m \choose i}\lambda^{m-i}J_{n}\left(0\right)^{i}`$
