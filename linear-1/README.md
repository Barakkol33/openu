```math
tr\left(A\right)A=\sum_{i=1}^{n}a_{ii}\cdot\left[A\right]_{ij}=\sum_{i=1}^{n}a_{ii}\cdot\left(\lambda_{i}u_{j}\right)
```

נסתכל על המכפלה $`A^{2}`$ $`\left(1\leq i,j\leq n\right)`$:

```math
A^{2}=\left[A\cdot A\right]_{ij}=\sum_{k=1}^{n}a_{ik}a_{kj}=\sum_{k=1}^{n}\lambda_{i}u_{k}\cdot\lambda_{k}u_{j}{\color{gray}\overset{}{\overbrace{{=}}}}\sum_{k=1}^{n}\lambda_{k}u_{k}\cdot\left(\lambda_{i}u_{j}\right){\color{gray}=}\sum_{k=1}^{n}a_{kk}\cdot\left(\lambda_{i}u_{j}\right)
```

כעת נניח שמתקיים $`\lambda_{1}\neq 0`$ וגם $`\lambda_{2}\neq 0`$:

```math
\lambda_{1}\sin x+\lambda_{2}\cos x=\boldsymbol{0}
```

```math
\lambda_{1}\sin x=-\lambda_{2}\cos x
```

```math
\lambda_{1}^{2}\sin^{2}x=\lambda_{2}^{2}\cos^{2}x
```

ידוע שמתקיים $`\sin^{2}x+\cos^{2}x=1`$ ולכן:

```math
\lambda_{1}^{2}\sin^{2}x=\lambda_{2}^{2}\left(1-\sin^{2}x\right)=\lambda_{2}^{2}-\lambda_{2}^{2}\sin^{2}x
```

```math
\sin x=\pm\sqrt{\frac{\lambda_{2}^{2}}{\lambda_{1}^{2}+\lambda_{2}^{2}}}
```

אמנם, ידוע כי $`\sin x`$ היא אינה פונקציה קבועה, ולכן הגענו לסתירה.

### טענות עזר (לא לציטוט)

#### ($`\ast`$)

יהיו $`U,W`$ תת מרחבים לינאריים של מרחב $`V`$. נוכיח שמתקיים $`\left(U+W\right)^{\perp}=U^{\perp}\cap W^{\perp}`$ וגם $`U+W=\left(U^{\perp}\cap W^{\perp}\right)^{\perp}`$.

נתחיל בלהראות שמתקיים $`\left(U+W\right)^{\perp}\subseteq U^{\perp}\cap W^{\perp}`$. יהי $`v\in\left(U+W\right)^{\perp}`$. וקטור זה אורתוגונלי לכל איבר ב-$`U+W`$, ובפרט הוא אורתוגונלי לכל איבר ב-ֹ$`U`$ ולכל איבר ב-$`W`$ (זאת כיוון שמרחבים אלה מוכלים ב-$`U+W`$). לפיכך, $`v\in U^{\perp}`$ וגם $`v\in W^{\perp}`$, כלומר $`v\in U^{\perp}\cap W^{\perp}`$. ובכך הוכחנו את הכיוון הראשון.

כעת נראה ש- $`U^{\perp}\cap W^{\perp}\subseteq\left(U+W\right)^{\perp}`$. יהי $`v\in U^{\perp}\cap W^{\perp}`$. נסתכל על וקטור $`v'\in U+W`$. וקטור זה מוגדר בצורה $`v'=u+w`$ כך ש $`u\in U`$ ו-$`w\in W`$. מכאן נובע שהמכפלה $`v\cdot v'`$ היא: $`v\cdot v'=v\left(u+w\right)=vu+vw`$. מכיוון ש-$`v`$ שייך ל-$`U^{\perp}`$ אז $`vu=0`$ ומכיוון ש-$`v`$ שייך ל-$`W^{\perp}`$ אז $`vw=0`$. נסיק מכך ש-$`vv'=0`$, זאת אומרת ש-$`v'`$ אורתוגונלי לכל וקטור ב-$`U+W`$. לכן הוא שייך ל-$`\left(U+W\right)^{\perp}`$. ובכך הוכחנו את הכיוון השני.

לסיכום הוכחנו ש- $`\left(U+W\right)^{\perp}=U^{\perp}\cap W^{\perp}`$.

הטענה השניה מתקבלת אם ניקח את השיוויון הנ"ל ונמצא את האורתוגונלי של כל צד בשיוויון, בצירוף העובדה ש-$`\left(U^{\perp}\right)^{\perp}=U`$ (משפט 12.3.2).
